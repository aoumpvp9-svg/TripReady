# ✈️ TripReady - 여행 준비물 체크리스트 웹앱

안티그래비티 및 모든 모던 브라우저에서 실행 가능한 여행 준비물 체크 웹페이지입니다.
외부 라이브러리나 복잡한 백엔드 설정 없이 순수 **HTML5, CSS3, Vanilla JavaScript**로 구현되어 가볍고 빠르며 안정적입니다.

---

## 🌟 주요 특징 및 디자인

- **현대적 & 감각적인 디자인**: 깔끔한 화이트톤 배경과 비비드한 블루 포인트 컬러 테마 적용
- **카드 형태의 카테고리 그리드**: 의류, 세면도구, 전자기기 등 6개 주요 카테고리를 직관적인 카드로 배치
- **완벽한 반응형 지원**: PC, 태블릿, 모바일 화면 크기에 맞춰 레이아웃 자동 최적화
- **실시간 통계 및 프로그레스 바**: 전체 준비물 수, 완료 수, 남은 수, 완료율(%) 및 달성도 게이지 바 제공
- **LocalStorage 영구 보관**: 체크 상태와 새로 추가한 준비물이 브라우저에 안전하게 자동 저장되어 새로고침 후에도 유지
- **부드러운 인터랙션**: 커스텀 체크박스, 취소선 효과, 토스트 알림, 확인 모달

## 🚀 필수 구현 기능

1. **체크박스 & 취소선 토글**: 각 항목 완료 시 체크박스 애니메이션 및 텍스트 취소선 표시
2. **카테고리별 전체 완료 토글**: 카드 우상단 버튼으로 해당 카테고리 전체 체크/해제 가능
3. **새 준비물 추가**: 카테고리 선택 및 품목명 입력 후 추가 (엔터 키 지원, 빈 값 및 중복 방지 예외 처리)
4. **준비물 삭제**: 각 항목 옆 삭제(휴지통) 버튼으로 불필요한 항목 즉시 제거
5. **실시간 현황 대시보드**: 전체/완료/미완료 개수 및 완료율 실시간 자동 계산
6. **동적 프로그레스 바**: 진행률에 따라 실시간 게이지 변화 (100% 완료 시 축하 배지 변경)
7. **카테고리 탭 필터링**: 전체 보기 및 6개 카테고리 개별 보기 지원, 탭별 준비물 개수 배지 제공
8. **브라우저 로컬 저장(LocalStorage)**: 새로고침하거나 브라우저를 닫았다 열어도 상태 유지
9. **전체 초기화 기능**: 상단 '전체 초기화' 버튼 클릭 시 확인 모달 표시 후 초기 22종 상태로 복원

## 📁 파일 구조

```
TripReady/
├── index.html        # 메인 웹페이지 구조 및 시맨틱 마크업
├── style.css         # 모던 화이트 & 블루 디자인 스타일시트
├── app.js            # 데이터 관리, 로컬스토리지, 인터랙션 로직
├── serve.js          # 무의존성 경량 Node.js 로컬 웹서버
├── serve.ps1         # PowerShell 원클릭 실행 스크립트
├── start.bat         # Windows 파일 탐색기 더블클릭 실행 배치 파일
├── test_logic.js     # 핵심 비즈니스 로직 단위 테스트 스크립트
└── README.md         # 프로젝트 안내 문서
```

## 💻 실행 방법

### 방법 1. 간이 웹서버로 실행 (추천)
- `start.bat`을 더블 클릭하거나,
- 터미널에서 다음 명령어를 실행합니다:
  ```powershell
  node serve.js
  ```
  이후 브라우저에서 `http://localhost:3050`으로 접속합니다.

### 방법 2. 브라우저에서 직접 열기
- `index.html` 파일을 더블 클릭하여 크롬, 엣지 등 브라우저로 바로 실행할 수 있습니다.
